# Movie Watchlist
Веб-приложение для ведения списка просмотренных фильмов и сериалов. Пользователи могут искать фильмы, добавлять их в "Буду смотреть" и ставить оценки.

## Основной функционал
- Поиск фильмов через внешнее API
- Личные списки (Любимое, Буду смотреть)
- Оценки и комментарии
